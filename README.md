# Зертханалық жұмыс 9 — CI/CD

GitHub: https://github.com/Jamspaq/lab-9

`index.html` файлын браузерде ашыңыз. `.github/workflows/ci-cd.yml` push және pull_request кезінде master тармағына іске қосылады.

Build, Test және Deploy қадамдары тапсырмадағы echo мысалдарын орындайды. Deploy — шартты орналастыру; нақты production хостинг жасалмайды.
